# Codebase File Index

A file-by-file map of all three repositories that make up the car rental platform. Generated by reading every source file; descriptions reflect actual code behavior, not just filenames.

- **test_rent** — Express + Prisma + PostgreSQL backend API, shared by both frontends
- **rent_a_car_admin** — Next.js/TypeScript admin panel (Super Admin / Manager)
- **rent_a_car** — Next.js customer- and driver-facing site (public browsing + customer/driver dashboards)

Legend: 🔶 = component uses mock/local-state data, not wired to a real backend field (documented in-code as a known gap).
